**AI Mood Canvas** is an AI-powered app that transforms **user moods** into **art and music** using **Google AI Studio (Gemini API)**.  
It’s a perfect blend of **creativity, AI, and user-centric design**.

---

<details>
<summary>🚀 Features</summary>

- 🧠 **Mood Detection** – Understands user emotions via text input.  
- 🎨 **AI Art Generation** – Generates images reflecting the mood.  
- 🎵 **Mood Music Linking** – Suggests YouTube tracks matching emotional tone.  
- ⚡ **No Deployment Needed** – Works inside Google AI Studio or locally.  
- 💬 **Enhanced Prompts** – Optimized Gemini prompts for better results.

</details>

---

<details>
<summary>📂 Tech Stack</summary>

| Component        | Technology                          |
|-----------------|------------------------------------|
| Frontend         | React + TypeScript + Vite           |
| AI Model         | Google Gemini API (via AI Studio)   |
| Music Integration| YouTube Data Linking                |
| Styling          | TailwindCSS                         |
| Hosting          | Preview inside AI Studio            |
</details>

---

<details>
<summary>🖥️ How It Works</summary>

1. User enters a **mood or feeling** (e.g., “I feel calm”).  
2. **Gemini API** interprets the text and determines the emotional context.  
3. AI generates:  
   - 🎨 Artwork matching the mood  
   - 🎵 Suggested YouTube track aligned with the mood  
4. Preview shows results instantly without any deployment.
</details>

<details>
<summary>🖥️ How to Run Locally</summary>

1. **Clone the repository**  

git clone https://github.com/navsss123/AI-Mood-Canvas.git

2. **Navigate into the project folder**

       cd AI-Mood-Canvas


3.**Install dependencies**

      npm install
4.**Start the development server**

      npm run dev
5.**Open the app**

    Open your browser and go to the URL shown in terminal (usually http://localhost:5173)

     You can now preview and test the app locally.

⚠️ Note: The Gemini API integration works through Google AI Studio, so some functionality may require API access or Studio preview.

</details>
